Hướng dẫn cài đặt Server — Club V e-Gaming
!
Chuẩn bị trước khi bắt đầu
  • technote-deploy.zip — copy từ máy cũ sang USB hoặc mạng nội bộ
  • firebase-service-account.json — trong thư mục server\ của máy cũ
  • ngrok authtoken — đăng nhập dashboard.ngrok.com → Your Authtoken
  • VAPID public key — Firebase Console → Project Settings → Cloud Messaging → Web Push certificates
  • Tắt ngrok trên máy cũ trước khi dùng máy mới quan trọng
1
Giải nén project
  1. Copy technote-deploy.zip vào ổ C:\ của máy mới
  2. Click phải vào file ZIP → Extract All… → giải nén vào C:\TechNote
  3. Copy firebase-service-account.json vào đúng vị trí:
    C:\TechNote\server\firebase-service-account.json
✓
Kết quả đúng: thư mục C:\TechNote\ chứa các thư mục server\, frontend\, deploy\
2
Chạy install.bat
  1. Mở File Explorer, vào C:\TechNote\deploy\
  2. Click phải vào install.bat
  3. Chọn "Run as administrator"
  4. Cửa sổ đen hiện ra — làm theo hướng dẫn bên dưới

Nếu Docker chưa được cài

Script sẽ tự cài Docker Desktop rồi dừng lại và báo:

  1. Khởi động lại máy tính
  2. Sau khi vào Windows: mở Docker Desktop, đồng ý license
  3. Đợi icon Docker 🐳 xuất hiện ở góc dưới phải taskbar
  4. Vào lại C:\TechNote\deploy\ → click phải install.bat → Run as administrator
⚠
Không chạy lại install.bat trước khi Docker Desktop hiện icon trên taskbar — sẽ báo lỗi

Quản lý sau khi cài

Quản lý services (mở services.msc hoặc dùng lệnh):

net stop TechNote
net start TechNote
net stop TechNote-ngrok
net start TechNote-ngrok

Xem log:

C:\TechNote\logs\technote.log
C:\TechNote\logs\ngrok.log

Cập nhật phiên bản mới (sau khi có ZIP mới):

  1. Copy technote-deploy.zip vào C:\ (cùng cấp với thư mục TechNote)
  2. Click phải C:\TechNote\deploy\update.bat → Run as administrator

Lưu ý quan trọng
⚠
Máy cũ phải tắt ngrok trước khi máy mới chạy — một static domain chỉ hoạt động trên 1 máy cùng lúc. Nếu không tắt, ngrok trên máy mới sẽ không kết nối được.
ℹ
Dữ liệu cũ (reports, users) lưu trong Docker volume. Nếu muốn chuyển dữ liệu, cần export DB từ máy cũ trước.
✓
PostgreSQL tự khởi động sau reboot nhờ Task Scheduler (delay 1 phút 30 giây để Docker kịp load).
